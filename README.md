# ADNI-Cognitive-Assessment

### Project Background

This research builds upon an earlier CSE641 Computer Vision course project undertaken collaboratively by Dhriti Gandhi, Yash Shah, Ura Modi, and Devashree Parikh at Ahmedabad University. The initial project explored computer-vision approaches to Alzheimer's disease using MRI-derived features, including MedicalNet and FastSurfer representations.

The present repository documents a subsequent set of experiments conducted by Devashree Parikh, investigating MRI representation learning, cognitive assessment, longitudinal prediction, classification, and leakage-aware evaluation. The relationship between the two projects is acknowledged to distinguish the original collaborative work from the subsequent experiments.
